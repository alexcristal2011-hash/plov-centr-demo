# plov-centr-demo

Отдельная демонстрация нового меню ресторана «Плов Центр» для согласования дизайна. Действующий сайт на Tilda и его оплата не изменяются.

В демо: 147 позиций, 11 категорий с фотографиями, поиск, сортировка, сведения о блюде и локальная пробная корзина. Заказы и платежи не отправляются; регистрации и серверной части нет. Корзина сохраняется только в sessionStorage браузера посетителя.

Использованы предоставленные рестораном фотографии. Там, где изображения нет, показана нейтральная заглушка. Все изображения, которые были в готовом прототипе, включены в каталог `assets/`.

Данные — предоставленный экспорт каталога от 30.08.2026. Первые 36 названий, цен и изображений сверены с отображаемым меню plov-delivery.ru 21.10.2026; остальные цены — снимок из экспорта. Дополнительная наценка не применялась. Перед реальным запуском нужно сверить весь актуальный каталог и отдельно подключить обработку заказов и оплату.

## Публикация GitHub Pages

В настройках репозитория откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку **main**, папку **/(root)** и сохраните. После успешной публикации ссылка появится в разделе Pages.

Сайт полностью статический: `index.html`, `app.css`, `app.js`, `menu.json` и `assets/`. Файл `.nojekyll` отключает ненужную обработку Jekyll. Относительные пути поддерживают размещение в подпапке репозитория GitHub Pages.
